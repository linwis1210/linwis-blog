# 2026-09-18 CLI slug 输入体验修复

## 问题（用户实测反馈）

标题「什么是 Claude Code」（中文合法）→ slug 提示「标题含非 ASCII 字符，请手动输入」：
1. 用户不知道要输入什么格式，把标题原样粘贴 → 被拒；
2. 输入 `What is Claude Code`（大小写/空格）→ 再次被拒——**本可自动规范化接受**。

## 修复内容（Builder）

`scripts/lib/scaffold.mjs`（或相关处）：

1. **slug 手动输入自动规范化**：trim → toLowerCase → 空格/下划线连续段折叠为单个 `-` → 去除首尾 `-` → 再校验；规范化后合法即接受并回显规范化结果（如 `What is Claude Code` → `what-is-claude-code`）；仍含非 ASCII/非法字符才拒绝。
2. **提示语改进**：无建议场景（中文标题）的 slug 提示附格式示例，如 `Slug（URL 文件名，英文小写连字符，如 what-is-claude-code）:`。
3. post 与 project 两脚本同规则。

## 验证（Leader 直接客观检查）

- `What is Claude Code` → 接受为 `what-is-claude-code`
- `  Claude_Code  `（空格+下划线+首尾空白）→ `claude-code`

- 参数模式 `--slug "What is Claude Code"` 同样规范化
