# Definition of Done — v1.0

v1.0 可以正式发布的条件：

1. 首页、Blog、Projects、Archive、About 正常。
2. Markdown/MDX 写作体验完整。
3. 搜索与 Command Palette 正常。
4. 手机端体验完整。
5. SEO / RSS / Sitemap 正常。
6. Giscus 可用且失败不影响正文。
7. CI 全部通过。
8. Docker 可独立启动。
9. GitHub Actions 可自动部署。
10. 部署失败可回滚。
11. 新服务器可以快速重建。
12. Lighthouse 达到目标。
13. ICP 等正式上线要求处理完成。
14. `v1.0.0` GitHub Release 发布。
